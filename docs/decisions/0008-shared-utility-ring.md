# 0008: Share utility choices while retaining native execution

Status: maintained
Reviewed: 2026-10-14
Evidence: [requirement R14](../REQUIREMENTS.md),
[implementation proof](../reference/SHARED-UTILITY-RING-RUNTIME-2026-10-14.md),
[utility model](../../addon/ConsolePort_Forever/Rings/Utility.lua),
[native adapter](../../addon/ConsolePort_Forever/Adapters/SharedUtility.lua).

The user authorizes a shared default utility ring, continued fixes/qualification
and deployment until manual Retail testing is needed. First eligible startup
enables it. A persistent independent slash disable and reload contain feature
failures without reinstalling. This utility-only exception to
[GUID ring ownership](0003-character-state-and-manual-edits.md) leaves personal
class rings, account Ping, bindings, pages, feedback and native dispatch intact.

Keep one account archive of stable manual choices and a derived native default
view. Filter unavailable/pending entries before noisy native validation. Capture
explicit native add/remove, completed reorder and confirmed global Clear;
availability changes are not deletions. Scope character macros, personal nested
rings, equipment and positional references to their GUID. Unresolved identities
stay archived without guessed execution; macro drift never uses fuzzy retargeting.

Guard native RefreshAll before compiled DATA/META change while a wheel is held,
combat/editor/review/setup is active or context/owner is unavailable. Explicit
native edits in the same qualified context retain their immediate rebuild outside
hard blockers. Preserve autoassigned extras and immediate feedback. Resume from
close/readiness/regen/review completion with no polling; unchanged item work skips
rebuilding. Preserve bounded before/desired/owner/readback receipts.

At PLAYER_LOGOUT, retain the master and serialize only timeless menu commands
and metadata in the public native default seed. No protected write, native refresh
or disk/WTF operation occurs. This prevents late native startup from validating
a previous spec's names before attachment. Next eligible startup projects the
master. Initial adoption cannot erase a legacy message emitted before activation.

`/cpfutility off` persists false, stops work and retains an owned current fallback
for disabled reload. `/cpfutility on` requires reload. Disabled startup installs
no utility hooks, classifier, worker, projection or utility-only subscriptions.
Archives and prior GUID data remain. Constructor failure is latched once per
session and cannot remove the command bootstrap. Store schema3/revision20 remain;
the additive master has version1 and two projection receipts. Offline proof is
not Retail taint/timing/rendering/persistence/CPU acceptance; K04/K05 remain open.
