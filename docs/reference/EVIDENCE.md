## Separate four dimensions

| Dimension | Labels and limits |
| --- | --- |
| Forever evidence | Source-supported at a pinned build; officially described; directly client-observed; unknown. Source flow does not establish engine outcomes. |
| Project intent | User-approved; deliberately different; deferred/gated; withdrawn; unresolved recommendation. |
| Implementation | Active under named prerequisites; loaded but inactive; privately prepared; absent; superseded. |
| Validation | Inspected source; offline regression-qualified; packaged; installed/read back; user accepted specific Retail cases; untested. |

A behavior can be requested, loaded, tested and still disabled. A selected
requirement can intentionally differ from Forever. A live symptom can be verified
while its root cause remains unknown. Do not collapse these into “implemented”
or “verified parity.” Recommendations/hypotheses need their own explicit label.

Prefer existing manifests and narrow source links over copied manuals. Remote
moving branches are discovery sources; hashes/commits identify retained evidence.
New screenshots/observations need candidate/context/steps and actual result.

## User authority and uncertainty

Direct user requests/answers establish intent. Agent conclusions and generated
reports establish only what their evidence supports. Historical authorization
is scoped and may be fulfilled, withdrawn or superseded. Store a short necessary
quotation/date/session reference rather than publishing raw personal transcripts.

Saved disk files establish persisted values, not effective current engine input.
Offline host models do not certify taint/hardware/rendering. “Unknown” should
state what observation would resolve it. A stale review date signals a need to
review, not permission to invent freshness or silently infer a requirement.

Maintained pages carry review metadata and links. Historical evidence remains
unchanged and excluded from maintained-page validation. Update affected claims
on behavior/API changes and preserve supersession links.
