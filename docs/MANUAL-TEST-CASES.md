# Retail tests after candidate.3

Use the controller for the input steps. On the current PS layout: Cross = PAD1, Circle = PAD2, Square = PAD3, Triangle = PAD4; L2 = Shift, R2 = Ctrl; L3/R3 = stick clicks. If your interface cursor shows different configured face prompts, follow those native prompts for bag/window actions. Record each ID as PASS, FAIL or UNAVAILABLE, with the exact action, class/spec and `/cpf diagnose` output on failure. File-audit and offline results do not count as these hardware passes.

First complete tests 01–07 on the current Paladin. Then run the remaining available cases. Use a training dummy or a low-risk quest for combat/temporary modes. An unavailable vehicle, quest, spell, pet or cinematic is UNAVAILABLE rather than PASS.
